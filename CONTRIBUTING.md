# Contributing to PlayerVaults

Thank you for considering contributing to PlayerVaults! 

## How to Contribute

### Reporting Bugs
Before creating a bug report, please check existing issues to see if it has already been reported. When creating an issue, please include:
- A clear description of the problem.
- Steps to reproduce the bug.
- Your server version (e.g., Paper 1.20.4) and console error logs (if applicable).

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your Java code follows clean coding conventions and standard formatting.
3. Test your changes on a Paper server before submitting.
4. Open a Pull Request with a clear description of the proposed changes.
