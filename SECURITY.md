# Security Policy

## Supported Versions

The table below details which versions of **PlayerVaults** are currently supported with security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

We strongly recommend always running the latest release on a modern **Paper / Spigot 1.20+** server to ensure data stability and security.

---

## Reporting a Vulnerability

We take the security and integrity of player data (such as item duplication or vault access exploits) very seriously.

If you discover a security vulnerability or exploit in **PlayerVaults**, please follow these guidelines:

### How to Report
- **Do NOT** open a public GitHub Issue for security vulnerabilities or item duplication exploits.
- Send a private message or open a private report detailing the vulnerability.
- Include step-by-step instructions or video evidence showing how to reproduce the issue.
- Include relevant details about your environment (Minecraft version, Paper build, server software, and installed plugins).

### Response Expectations
- **Initial Response:** You will receive an acknowledgment of your report within **24 to 48 hours**.
- **Assessment:** We will evaluate the reported vulnerability and provide an estimated timeline for a patch.
- **Resolution:** If the vulnerability is confirmed, a security patch will be pushed in a new release as soon as possible.
